TEST SCOPE
The runtime test compiles the REAL RFLink bridge/motor and 48, 47 or 2 original
RX plugins together with the NEW C++ hub/event implementation.
The known 085372/08 and 01fac2/08 keys use synthetic raw 300/900-us waveforms
through the bridge. These exercise JSON dedup AND the accepted-frame callback.
Additional arbitrary-key routing, learning-pool and time-rollover fixtures feed
the documented accepted-frame interface directly. They do not prove that every
arbitrary synthetic raw pattern is decoded as EV1527 by every plugin selection.
The event/text/binary-sensor and JSON APIs are HOST TEST DOUBLES, not a running
ESPHome/ArduinoJson/API stack. No RF hardware, router, OTA or HA is emulated.
ASan/UBSan are enabled on the C++ runtime and state-machine tests.

IMPORTANT EXISTING LIMITATION REPRODUCED
With the complete plugin selection, the synthetic 085372/04 300/900-us fixture
is decoded as Eurodomest before Plugin_061 is reached. With [61] it is EV1527.
The new layer preserves this upstream selection and correctly does NOT fabricate
an EV1527 gesture for the Eurodomest result; learning reports mode=message.
This regression test is intentionally present; the decoder order is NOT changed.
